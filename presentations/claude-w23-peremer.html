Что из этого следует для чтения любых недельных срезов

Звёзды за первую неделю жизни репозитория меряют не качество, а заметность запуска: попадание в рассылку, удачный заголовок, тред на Hacker News. Позиция в недельном топе — это ранг внутри окна наблюдения, а не прогноз. Проверяемым срез становится только при повторном замере.

Единственное правдоподобное объяснение падения на четверть и сильнее — чистка накрученных звёзд: GitHub периодически удаляет аккаунты, торгующие звёздами, и вместе с ними исчезают их отметки. Проверить это со стороны нельзя: API отдаёт только текущее число, историю удалённых отметок он не показывает. Поэтому вывод помечен как наиболее вероятное объяснение, а не подтверждённый факт — альтернатива (массовое разочарование и ручное снятие звёзд) выглядит менее правдоподобно, но не исключена.

Практический смысл: недельный топ уязвим к накрутке ровно потому, что порог входа в него низкий. Сто звёзд за неделю купить дёшево, и в снимке они неотличимы от настоящих. Второй замер их выдаёт.

Тема 1

Мульти-модельность: отвязать оболочку от вендора 4 репозитория

Claude Code — это оболочка (harness): сам агент, терминальный цикл, инструменты и работа с файлами. Модель, которая внутри думает, — отдельный слой. Тема недели была в том, чтобы разорвать эту связку.

Зачем это людям: оболочку хочется сохранить, потому что к ней привыкли и под неё написаны скиллы, а за инференс — платить там, где дешевле, или там, где уже оплачено.

★258 → ★425 · OnlyTerp/UltraCode-Shim Python

Лидер той недели. Локальный прокси, дающий режим ultracode поверх любой модели, которую вы уже оплачиваете у другого провайдера. Настройка сводится к одному config.json, дальше агент донастраивает себя через AGENTS.md. Самый прямолинейный ответ на задачу: ничего не переписывать, подменить адрес модели.

★91 → ★211 · ethanhq/cc-fleet Go

«Флот» моделей. В отличие от простого прокси здесь акцент на оркестрацию: DeepSeek, GLM, Qwen, Kimi и MiniMax поднимаются как полноценные тиммейты или как одноразовые (one-shot) сабагенты под конкретную подзадачу, и несколько разных моделей работают параллельно под управлением одного дирижёра.

Две «вариации», оказавшиеся разными вещами

В июне mai-yyy/multi-llm-mcp и zhnt/loushang выглядели одинаково: Claude дирижирует и вызывает другие модели как внешние инструменты по протоколу MCP. Перемер показал разное. multi-llm-mcp остался MCP-сервером и вырос втрое, до ★114. loushang перерос исходную рамку: сегодня это самостоятельная оболочка с маршрутизацией провайдеров, устойчивыми сессиями, управлением инструментами и прослеживаемой сдачей работы. Заявка не «подключить чужую модель к Claude Code», а «сделать свой Claude Code».

Термины

  • Proxy / shim — промежуточный слой, перехватывающий запросы агента к модели и перенаправляющий их в другую; агент подмены не замечает.
  • Multi-LLM orchestration — один агент-дирижёр дробит задачу, раздаёт куски разным моделям и собирает результат.
  • MCP (Model Context Protocol) — открытый протокол подключения внешних инструментов и серверов к агенту; здесь через него агент дёргает сторонние модели как инструмент.
  • One-shot субагент — разовый дочерний агент на одну задачу, без состояния между вызовами.

Общение и soft skills

ayi-ai/ayi-nonviolent-communication — навык ННО: ненасильственное общение, англ. NVC, методика Маршалла Розенберга. Она предлагает отделять наблюдение от оценки, называть чувства и потребности и формулировать просьбы. Агент помогает переписать резкое сообщение в бесконфликтное по этой схеме. Кода в навыке нет вообще, и именно высокий рейтинг чисто гуманитарного навыка стал сигналом, что Skills вышли в мейнстрим за пределы разработки.

Наука и публикации

Chenruishuo/posterly — рост в 5,4 раза и третье место когорты сегодня. Генерация научных постеров: агент собирает постер одним файлом HTML/CSS и рендерит его в PDF через headless Chromium — браузер без интерфейса, используемый как движок печати. MrLee2R/Intelligrapher — навык научной графики: качественные иллюстрации и диаграммы для публикаций. Соседняя с posterly ниша визуализации.

Образование

Безопасность

Инструмент двойного назначения (dual-use): применим и для защиты, и для атаки, поэтому уместен только в легальном контексте — пентест по договору, CTF, обучение.

Справка

Глоссарий

Термины, встречающиеся в выпуске, — в одном месте.

  • harness (оболочка) — агент, терминальный цикл и инструменты; слой, отдельный от модели.
  • proxy / shim — слой подмены модели под капотом, незаметный для агента.
  • MCP (Model Context Protocol) — открытый протокол подключения внешних инструментов и моделей к агенту.
  • multi-LLM — несколько разных моделей под управлением одного дирижёра.
  • one-shot субагент — разовый дочерний агент на одну задачу, без состояния между вызовами.
  • персистентная память — состояние агента, переживающее перезапуск сессии.
  • Skill / SKILL.md — переносимый навык агента и его манифест с описанием и триггерами.
  • слэш-команда — способ запуска навыка (/имя).
  • AGENTS.md / CLAUDE.md / .cursorrules — файлы-правила разных агентных инструментов.
  • PTES — Penetration Testing Execution Standard, методология пентеста.
  • dual-use — двойного назначения: применимо и для защиты, и для атаки.
  • ННО / NVC — методика ненасильственного общения Маршалла Розенберга.
  • headless Chromium — браузер без интерфейса как движок рендера HTML в PDF.
  • Electron — упаковка веб-приложения в десктоп со встроенным Chromium; app-it обходится без него.
  • thinking block — подписанный блок рассуждений Claude; ломается при смене моделей.

Прозрачность исследования

Метод и оговорки

Как собран исходный срез, как сделан перемер и что в выводах не подтверждено.

Метод исходного среза

Через GitHub API брались репозитории, созданные за последние семь дней, отсортированные по звёздам. Для свежего репозитория общее число звёзд примерно равно набранному за неделю — поэтому «новизна ≈ популярность недели». Отдельным блоком шли зрелые гиганты, по которым на неделе была активность.

Метод перемера

4 сентября 2026, GET /repos/{owner}/{repo}, поля stargazers_count, language, archived. Проверены все 18 репозиториев когорты недели и все 7 зрелых. Июньские числа взяты из исходных обзоров как есть и отдельно не перепроверялись.

Не подтверждено

Объяснение просадки звёзд у трёх репозиториев чисткой накрученных отметок — наиболее вероятная, но непроверяемая со стороны версия: GitHub API отдаёт только текущее число звёзд и не показывает историю удалённых.
