Claude Code 2.1.288 → 2.1.295 — 8 релизов

  • onFailure: "block" для hooks (2.1.295) — command- или HTTP-hook, который не стартовал, вышел по таймауту или завершился неожиданным кодом, теперь может блокировать действие, а не пропускать его. Тем, кто держит на hooks защитные проверки, стоит включить. Заодно в 2.1.294 исправлены prompt- и agent-hooks, записанные инструкцией («Block commands that…»): они пропускали то, что должны были блокировать.
  • Параметр effort у Agent tool (2.1.292) — Claude запускает субагента на том уровне рассуждения, о котором его попросили. В 2.1.295 субагент заранее подгружает не больше 32 скиллов из поля skills; остальные доступны через Skill tool.
  • Моды получили новые события и вызовы (2.1.288–2.1.295) — prompt.autocomplete добавляет свои строки в автодополнение, $.model.complete принимает блоки с cache: true, agent.spawn видит агентов воркфлоу и может им отказать, tool.check получает agentId и требуемый организацией уровень одобрения (ceiling). Исправлено опасное: глубоко вложенный вход инструмента приходил в hook мода обрезанным без ошибки, и guard мог пропустить содержимое, которого не видел.
  • claude plugin install --marketplace <source> (2.1.292) — добавляет маркетплейс, если его нет, под теми же проверками политики, и ставит плагин одной командой. claude plugin validate перечисляет hooks мода на «запирающих» точках и показывает, есть ли у каждого .catch (2.1.290).
  • Auto mode на длинных сессиях (2.1.288) — когда разговор не помещается в клиентский классификатор безопасности, он сжимается, а не превращается в запрос разрешения на каждый вызов. Бюджет WebSearch в интерактивной сессии теперь пополняется — 100 вызовов в час — вместо обрыва после 200 (2.1.290).
