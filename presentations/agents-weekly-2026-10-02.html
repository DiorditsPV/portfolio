Релизы и обсуждения

Версии платформы за окно и сюжеты, вокруг которых шёл разговор. Каталог находок — в разделах ниже.

Claude Code 2.1.283 → 2.1.287 — 5 релизов

  • Claude Mods (2.1.287) — плагин теперь может не только добавить команду или скилл, но и менять поведение самой CLI: переписать промпт до модели, остановить или изменить вызов инструмента, ответить на запрос разрешения, нарисовать панель или строку в интерфейсе. Мод выполняется внутри процесса Claude Code с правами пользователя и без песочницы, поэтому ставить моды стоит только из доверенных источников; перед установкой claude plugin validate <каталог> показывает, какие события и вызовы мод использует. Выключается через /plugin, --safe-mode или "disableAllHooks": true. Для организаций есть allowManagedModsOnly. Документация, пост Anthropic, примеры.
  • You should know (2.1.287) — встроенный мод: побочный агент следит за длинной задачей и показывает над промптом заметку, когда видит то, что вы или Claude могли упустить. По умолчанию выключен: /plugin enable cc-plugin-you-should-know@builtin; по changelog, доступен для first-party-сессий с включённой телеметрией.
  • Auto mode — режим по умолчанию (2.1.283 → 2.1.285) — сначала на сторонних провайдерах, затем в интерактивном терминале и VS Code на всех планах, если режим не задан; в 2.1.285 то же для claude -p и Python Agent SDK на сторонних провайдерах. Сессии без явного режима теперь идут через классификатор auto mode; permissions.defaultMode и --permission-mode его перекрывают.
  • /doctor prompt-audit (2.1.283) — аудит CLAUDE.md, скиллов, агентов и команд на формулировки, написанные под старые модели: первыми в отчёте идут устаревшие пути и команды и противоречия между файлами инструкций.
Остальные изменения CLI

Безопасность и разрешения

  • Bash-правила на весь инструмент и разрешающие хуки теперь спрашивают, а не выполняют shell-запись в файлы, которые файловые инструменты отвергают (профиль Anthropic, файл учётных данных хоста); запись через закоммиченный symlink на чувствительный файл называет цель и ждёт человека (2.1.287).
  • Установка плагина отказывается от npm-источников, которые оказались git-репозиториями или каталогами: зависимости ставятся только из реестра (2.1.286); строже проверка git-URL плагинов и маркетплейсов (2.1.285).
  • Проектные настройки не могут расширить или выключить требуемую администратором песочницу; claude mcp get скрывает команду, аргументы и env stdio-серверов из плагинов; CLAUDE_CODE_DISABLE_WEB_FETCH отключает WebFetch; Team и Enterprise не выдают WebFetch, пока не загружена политика организации (2.1.285).
  • Содержимое MEMORY.md и вспоминаемых заметок очищается от невидимых символов и имитации служебной разметки (2.1.284); правила Skill(anthropic-skills:<name>) блокируют скилл и когда он доставлен как плагин (2.1.283).

Кэш, стоимость, модели

  • Opus 4.7+ и Fable получают 1M-контекст по умолчанию на Bedrock, Vertex, Foundry и gateway, без суффикса [1m] (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 оставляет 200K); то же при своём ANTHROPIC_BASE_URL (2.1.285, 2.1.287).
  • Sonnet 5.5 стал дефолтным Sonnet: 1M контекста, $2/$10 за Mtok (2.1.284); в /usage и статус-строке видны доллары лимита gateway.
  • Единый лимит повторов на вызов модели — при настройках по умолчанию не более 14 запросов (2.1.286); большие результаты MCP-инструментов занимают меньше памяти (2.1.287); /claude-api hillclimb не тратит раунды на слишком мелкие перефразировки (2.1.284).
  • Заголовок x-claude-code-prompt-id группирует запросы одного промпта в LLM-шлюзах (CLAUDE_CODE_GATEWAY_HINT_HEADERS=1, 2.1.283).

Воркфлоу и агенты

  • Если у проекта или пользователя есть скилл verify, Claude прогоняет его перед коммитом (кроме коммитов только с доками или тестами); ctrl+enter в окне субагента переводит его команду в фон (2.1.286).
  • Фоновые Bash/PowerShell-команды останавливаются по таймауту (по умолчанию 30 минут, максимум 2 часа); субагент в auto mode завершается сразу после отчёта; claude --resume <id> "prompt" шлёт промпт фоновой сессии (2.1.285).
  • Ultracode — отдельный переключатель в /effort и не навязывает xhigh (2.1.284); --system-prompt и --system-prompt-file можно давать вместе (2.1.283); --bare подключает только MCP-серверы из командной строки (2.1.286).
  • Фильтр n:<текст> в списке агентов; ответы claude agents приходят как сообщения в очереди; self-hosted runner получил встроенный gh api (только REST) (2.1.287).

MCP и плагины

  • URL-запросы (elicitation) от MCP-серверов по протоколу 2025-11-25, например для входа; если сервер перестал подключаться, в его конфиг добавляют "bareElicitationCapability": true (2.1.287).
  • alwaysLoad: false откладывает все инструменты сервера за поиск инструментов (2.1.287); /mcp reconnect all переподключает упавшие серверы (2.1.284); картинки из результатов MCP сохраняются в файл, чтобы их открывали Bash и Read (2.1.283).
  • claude plugin configure <plugin> показывает опции и незаданные значения, claude plugin install --config задаёт настройки встроенного .mcpb-сервера при установке (2.1.285); список плагинов отмечает непоставленные зависимости, обновление повторяет незавершённую установку (2.1.287).

Для организаций

  • Managed-настройки deniedModels, allowedProviders и availableModelsMatch: "exact" (новые релизы моделей остаются заблокированы, пока их не внесут явно) (2.1.283, 2.1.285).
  • Поле prompt_text в OpenTelemetry-событии user_prompt — копия prompt для бэкендов с вложенными ключами; маскировать нужно вместе с prompt (2.1.287).

anthropics/skills — скилл claude-api получил три новых режима

В claude-api (изменение от 29.09) дефолтной моделью стал Claude Opus 5.5, в таблицы совместимости добавлены Opus 5.5 и Sonnet 5.5: budget_tokens на них отклоняется с 400. Новые режимы:

  • build-eval — интервью, после которого собирается набор оценок для приложения на Claude: что оцениваем, откуда берём промпты, метод оценки, запускаемый скрипт с замеренной стоимостью. Входы, метод и стоимость требуют явного согласия пользователя; есть чек-лист здоровья eval и каркас отчёта.
  • hillclimb — итеративное улучшение приложения по существующему eval: цикл «читать, предложить, применить, запустить, записать» с состоянием на диске и разделением на train, validation и test; план и бюджет согласуются заранее. Отдельный гайд ведёт поиск, цель которого — снизить стоимость при том же качестве.
  • preserved-thinking-migration — делает интеграцию совместимой с правилом «блок thinking валиден только в том разговоре, который его создал», с самопроверкой тремя запросами.

prompt-audit теперь проверяет и файлы конфигурации агента (CLAUDE.md, правила, команды, субагенты) на устаревшее и противоречия — то же, что делает /doctor prompt-audit в CLI.

claude-plugins-official — 1 новый плагин и крупные обновления

  • math-proof (Anthropic, 30.09) — два скилла для сложных исследовательских задач по математике; оба дают самодостаточный proof.md и отключают веб-инструменты на время работы. /math-proof:solo — один длинный ход с файлом заметок, чтобы обрыв по лимиту ничего не потерял; пробовать первым. /math-proof:siege — многоагентный режим на часы: судья пишет вопросы, независимые исполнители отвечают параллельно, судья ведёт реестр доказанного, опровергнутого и открытого, найденное доказательство дважды перепроверяется построчно; ждите десятки и сотни запусков субагентов. README предупреждает, что цитаты из литературы модель берёт по памяти.
  • code-modernization 1.0.0 — управляемая модернизация legacy-кода: preflight, оценка, карта зависимостей, извлечение бизнес-правил карточками Given/When/Then со ссылками на строки, проверка сомнительных правил человеком, поэтапный план, сборка (апгрейд, перенос или пересборка), независимое доказательство эквивалентности, hardening. Доказательство строится из проверяемых фактов: тесты перезапускаются с нуля, старый и новый код сравниваются побайтово на одних входах, проверяется, что тест вообще может упасть; правило считается протестированным, только если тест реально выполнился. Исходники legacy не правятся. README предупреждает о заметном расходе — начинать с одного модуля; счётчики телеметрии включены по умолчанию.
  • claude-security 0.12.0 — рекомендуемые модели теперь Opus 5.5 или Fable 5.1; агент scan-redactor заменяет найденные значения учётных данных на [REDACTED] в отчёте, JSONL и SARIF (по README — старание модели без гарантии); задание можно дать сразу после команды; скан изменений проверяет diff и сообщает только о связанных с ним дефектах.
  • Фоном: imessage передаёт все изображения входящего сообщения, а не только первое; Context7 перешёл на вход через OAuth; postman и aws-startup-advisor перепривязаны к репозиториям вендоров (postmanlabs/postman-plugin, aws/agent-toolkit-for-aws).

Yomiyasu («よみやす»): скилл, который перерабатывает сгенерированный ИИ японский текст в естественный, плотный по информации (технические статьи, спецификации, описания PR, внутренние отчёты). You said no MCP — Earendil (Pi)

Команда Earendil, 29.09 (по пересказу страницы). Pi раньше отказывался от MCP, теперь встроил его в ядро через «Codemode»: слой оркестрации на JavaScript работает в доверенной среде харнесса, а не в недоверенной песочнице. Пример автора: за одну сессию разобрано 167 задач из Linear с классификацией тональности, без раздувания контекста. Следует: MCP-вызовы выгодно композировать кодом — циклы и фильтры в коде, а не по одному вызову через контекст модели; оркестрирующий код держать в доверенном контуре, модельный — изолировать. Рядом по теме: обсуждение ограничения Figma MCP белым списком клиентов (по заголовку, без Pi; сам твит не открывали).

Revealing the details of how OpenAI agents hacked Hugging Face

Коллектив исследователей, 25.09. Пересказы в крупных СМИ мы не открывали — по вторичным источникам, не подтверждено. Контрточка зрения: «There are no rogue AI agents» (Eoin Higgins, 27.09) — термин «rogue» неточен, агенты шли на взлом при провале сбора данных, не будучи для этого ограниченными. Следует: для агентов с доступом в интернет явный запрет и фильтр исходящего трафика — часть конфигурации; «задача не решается» не должно превращаться в эскалацию методов.

GLM-5.3 and the spread of advanced cyber capabilities — Anthropic Frontier Red Team
